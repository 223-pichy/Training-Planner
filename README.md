## Описание программы

Training Planner - это GUI-приложение для ведения дневника тренировок. Приложение позволяет добавлять записи о тренировках (дата, тип тренировки, длительность), фильтровать записи по типу тренировки и дате, сохранять и загружать данные в формате JSON.

### Возможности:
- ✅ Добавление тренировок с указанием даты, типа и длительности
- ✅ Фильтрация записей по типу тренировки (выбор из списка)
- ✅ Фильтрация по точной дате
- ✅ Сохранение данных в JSON-файл
- ✅ Автоматическая загрузка данных при запуске
- ✅ Автоматическая подстановка текущей даты
- ✅ Валидация вводимых данных (формат даты, положительная длительность)

## Инструкция по запуску

### Требования:
- Python 3.6 или выше
- Установленная библиотека Tkinter (обычно идёт в комплекте с Python)

### Запуск:
1. Откройте терминал или командную строку
2. Перейдите в директорию проекта:
   ```bash
   cd training_planner
   Примеры использования
Добавление тренировки:
Заполните все поля формы:

Дата (ГГГГ-ММ-ДД): "2026-05-22" (автоматически подставляется текущая дата)

Тип тренировки: выберите из списка (например, "Бег")

Длительность (мин): "45"

Нажмите кнопку "Добавить тренировку" — запись появится в таблице

Фильтрация:
По типу тренировки:

Выберите тип из выпадающего списка (например, "Плавание")

Нажмите "Применить фильтр" — в таблице останутся только тренировки выбранного типа

По дате:

Введите дату в поле "Фильтр по дате (ГГГГ-ММ-ДД)" (например, "2026-05-22")

Нажмите "Применить фильтр" — покажутся тренировки только за этот день

Совместная фильтрация: фильтры по типу и дате работают одновременно

Сброс фильтров: нажмите "Сбросить фильтр" — покажутся все тренировки

Просмотр всех тренировок:
Таблица автоматически отображает все добавленные тренировки. После добавления новой тренировки таблица обновляется.

Тестовые данные (примеры для проверки)

Дата	Тип тренировки	Длительность (мин)
2026-05-20	Бег	30
2026-05-21	Плавание	45

2026-05-22	Силовая	50
2026-05-23	Йога	40

Проверка фильтрации:
После добавления попробуйте:

Отфильтровать по типу "Бег" — должны остаться тренировки за 20.05 и 23.05

Применить оба фильтра (тип "Бег" и дата "2026-05-23") — останется только одна тренировка (Бег на 35 мин)

Проверка валидации:
Попробуйте добавить тренировку с ошибками:

Ввести отрицательную длительность (например, "-30") → ошибка "Длительность должна быть больше 0"

Ввести буквы в поле длительности (например, "сорок") → ошибка "Введите корректное число"

Проверка сохранения:
Добавьте 2-3 тренировки

Закройте приложение

Откройте снова — тренировки должны остаться (автозагрузка из JSON)
